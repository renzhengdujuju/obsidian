

**1. 陈航（9.0）—— 工程深度最扎实，可信度最高**

- 企业实习有明确的量化优化：XML 定制复杂 SQL + 复合索引 + 连接池 8→100 + 5 秒结果缓存，50 并发错误率 **69.85%→1% 以内**、TP95 稳定 2s；监控播放链路统一入口支持 13 种终端、内外网 hls/hlss 自动切换，方案复用 3+ 项目。
- 自研项目覆盖真实难题：Lua 原子合并点赞关系与计数 + RabbitMQ 削峰（publisher-confirm/手动 ACK/死信重试）+ 定时对账，**1000 并发、单帖 500 并发、3030 混合随机三组实验零偏差**；ES 宕机 30s 半开探测自动降级回 DB；13 容器一键部署。第二个项目还做了 AI 文件工具路径白名单（越权拦截 100%）、Java 21 虚拟线程异步化、Redisson 三维令牌桶。
- 问答佐证：班级排名第二、项目独立开发并上线、有真实用户，GitHub 与线上站点均可打开——**简历内容与可验证物一致**，这在 11 人中只有极少数。
- 扣分点：实习仅 3 个月（2026.07–09），部分推荐/热度分设计需追问是否完全自研。

**2. 毛延新（8.6）—— Agent 架构能力最接近企业级**

- Text2SQL 全链路：Prompt 三轮迭代准确率 **50%→75%**；50+ 表上做表级 Embedding 召回 + 字段语义匹配 + Join 路径 BFS 的 Schema Linking，token 消耗 **-40%**；三层测试集 + Execution Accuracy 自动化评估，**66%→82%**。
- 多 Agent 达人评估系统：Pydantic Query Plan 拆硬/软条件 + 参数化 SQL 预筛，稠密向量 + BM25 + RRF + Cross-Encoder 精排，Top-10 召回 **91.6%**、条件抽取 **94.1%**；LangGraph 里把业务 State 与 RuntimeContext 分离、并行 Subagent、interrupt Checkpoint 支持暂停恢复与局部重跑，单次初筛 **4–6 小时→30 分钟**；MCP Streamable HTTP 只读工具 + 租户权限注入 + 超时/重试/熔断/降级/脱敏审计；用“LLM 只做事实抽取 + 程序侧引用校验/冲突检测”做防幻觉，引用支持率 **96.3%**。
- 同时有 Java 后端底子：EOMP 运维平台用 SSH 连接池做到百台/千台并发（≤10s）、双层 RBAC、XXL-JOB 巡检。
- 问答佐证：自评班级第一、项目 0→1 独立搭建并内网部署、18 名内部用户、累计评估 1200+ 候选人，另有 chatbi / talent-eval-agents 两个开源仓库。
- 扣分点：无公网 demo，部分指标（91.6%/96.3%）的评测样本与口径需要面试追问。

## 差一点入选：孙梦磊（8.1，我给 86）

孙梦磊的系统底层功底其实是全场最强之一：深势科技 Uni-Lab-OS 真实开源项目（WorkstationBase 可插拔框架、PLC/串口/以太网/ROS2 多协议、Modbus TCP、PyLabRobot/LIMS 报送），仪器驱动“AST 静态分析 + LLM 判别”把 **1538 个候选纳管 1017 个（66%）**，PROTIUM 设备广场用 Go+Gin+Next.js 做数字孪生配对；ICPC 四川银牌、蓝桥杯国三、RAICOM 国三；问答里三个项目均上线（rag.emoera.cn 一人全栈、200 用户）。

他之所以被挤出前三：**AI/Agent 架构深度与量化指标密度不如毛延新，岗位主流技术栈（Java 后端 + Agent）的匹配度不如唐俊峰**，实习方向也偏科研自动化。若这批简历是招“系统/平台/后端”而非“AI 应用”，他应当替换唐俊峰进前三。
