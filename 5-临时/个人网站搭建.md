# 个人网站搭建全流程实战：从零到 HTTPS 全链路打通 (renzhengdejuju.online)

**项目背景**：从零开始搭建一个可以被公网访问的个人网站，部署前端页面，并实现全站 HTTPS 加密。

---

## 🗺️ 整体架构流程

1. **基础设施**：购买 ECS 云服务器 -> 配置安全组 -> 注册域名
2. **运行环境**：部署 Nginx Web 服务器
3. **域名解析**：配置 DNS 解析（A记录、TXT记录）
4. **业务部署**：上传前端 HTML 文件
5. **安全加密**：申请 SSL 证书并配置 HTTPS
6. **合规要求**：提交 ICP 备案（关键前置）

---

## 第一阶段：基础设施与网络配置

### 1. 云服务器 (ECS) 与安全组
这个页面是购买阿里云ECS的页面
![[Pasted image 20261104153321.png]]

*   **操作**：购买阿里云 ECS（华东2 上海节点），系统为 Alibaba Cloud Linux 3。
*   **配置安全组**：这是网站能被访问的"大门"。必须手动放行特定端口。
    * 配置 ECS 安全组（放行网站端口）

		你的 ECS 默认可能只开放了远程连接端口，网站需要的 80（HTTP）和 443（HTTPS）端口需要手动放行。

1. 登录阿里云控制台，进入 **云服务器 ECS**，找到你的 `my-ECS` 实例。
    
2. 点击实例，进入 **安全组** 配置页面。
    
3. 在 **入方向** 添加规则：
    
    - 协议类型选 **自定义 TCP**
        
    - 端口范围填 **80/80**，授权对象填 **0.0.0.0/0**（表示允许所有人访问）
        
    - 同样再添加一条 **443/443** 的规则。[](https://jaq-doc.alibaba.com/docs/doc.htm?treeId=608&articleId=112651&docType=1)[](https://developer.aliyun.com/article/1712358)
        

完成这一步后，外部才能访问你服务器上的网站服务。
    *   协议：`自定义 TCP`，端口：`80/80`（HTTP），授权对象：`0.0.0.0/0`
    *   协议：`自定义 TCP`，端口：`443/443`（HTTPS），授权对象：`0.0.0.0/0`
    *   保留 `22`（SSH 连接）和 `3389`（RDP连接，如适用）。

### 第三步：域名解析（把域名指向 ECS）

1. 回到阿里云 **域名控制台**，找到 `renzhengdeju.online`，点击右侧的 **解析**。
    
2. 点击 **添加记录**：
    
    - **记录类型**：选 **A**
        
    - **主机记录**：填 **@**（代表 `renzhengdeju.online` 本身）；如果你想用 `www.renzhengdeju.online`，再添加一条主机记录为 **www** 的 A 记录。
        
    - **记录值**：填你 ECS 的 **公网 IP 地址**。
        
    - TTL 保持默认即可。[](https://help.aliyun.com/zh/dns/pubz-add-website-parsing?source=5176.11533457&spm=a2c6h.13066369.0.0.706c5316tSgdMA&type=copy&userCode=28kqeewo#1)[](https://developer.aliyun.com/article/1672695)
        

解析添加后通常很快生效，你可以用 `nslookup renzhengdeju.online` 检查是否已经指向你的 ECS IP。

### 第四步：ICP 备案（关键门槛）

如果你 ECS 买的是**中国内地地域**（如杭州、北京），**必须完成 ICP 备案，域名才能正常访问网站**。如果没备案，用域名访问通常会被阻断。

1. 登录阿里云 **ICP 代备案管理系统**。
    
2. 按系统引导填写：主体信息（你个人）、网站信息（域名 `renzhengdeju.online`、网站名称等）。
    
3. 上传所需材料（身份证等），完成核验。
    
4. 提交后等待 **阿里云初审（1~2 个工作日）**，初审通过后管局审核（**1~20 个工作日**）。[](https://help.aliyun.com/zh/document_detail/3043304.html#1)[](https://www.alibabacloud.com/help/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview?_v_=8732532874cd0dcd4dcea69b62bf68ed&_v_=8732532874cd0dcd4dcea69b62bf68ed#1#1)
    

**如果你 ECS 买的是中国香港或海外地域**，则无需备案，解析生效后即可直接访问。

### 第五步：配置 HTTPS（可选但建议）

备案通过（或确认无需备案）后，你可以在阿里云申请一张免费 SSL 证书，部署到 Nginx 上，让网站支持 `https://` 访问。这样浏览器地址栏会显示安全锁，体验更正式。
    *   添加 `A` 记录：主机记录填 `@`（代表根域名），记录值填 ECS 公网 IP。
    *   添加 `A` 记录：主机记录填 `www`，记录值填 ECS 公网 IP。

## 第二阶段：Web 环境部署

### 1. 安装 Nginx

*   **操作**：通过 Workbench 终端远程连接服务器。输入以下命令安装：

```bash
yum install nginx -y
systemctl start nginx
systemctl enable nginx
```

- **踩坑记录：端口冲突**。
    - **问题**：使用 `systemctl status nginx` 发现 Nginx 没起来，或者用 `netstat -tlnp | grep :80` 发现 80 端口被名为 `httpd`（Apache）的进程占用。
    - **解决**：强制停止 Apache 并禁用它，重新启动 Nginx。

```bash
systemctl stop httpd
systemctl disable httpd
systemctl restart nginx
```

### 2. 准备网页文件（注入灵魂）

- **操作**：本地编写 `index.html`（在线考试系统前端代码）。
- **上传**：使用 WinSCP 连接服务器（SFTP 协议，端口 22，root 账号+密码），将文件拖拽上传至 Nginx 默认网站目录：`/usr/share/nginx/html/`。

## 第三阶段：HTTPS 安全加固（最曲折的部分）

### 1. 申请免费 SSL 证书

- **操作**：在阿里云"数字证书管理服务"中，领取"个人测试证书（免费版）"。
- **踩坑记录 1：找不到免费入口**。
    - **问题**：直接在首页点购买，发现都要钱。
    - **解决**：必须进入"证书管理" -> "SSL证书管理" -> 点击"个人测试证书（原免费证书）"页签才能领取。

### 2. DNS 验证卡死（ERR_EMPTY_RESPONSE / 验证失败）

- **问题现象**：在证书申请页面添加了 `TXT` 记录后，点击"验证"一直提示"未检测到DNS记录值"。
- **排查过程**：
    - 本地 CMD 执行 `ipconfig /flushdns` 刷新缓存（需要管理员权限）。
    - 使用 `nslookup -type=TXT _dnsauth.renzhengdejuju.online 223.5.5.5` 指定阿里云公共 DNS 查询，一直报 `Non-existent domain`。
    - 使用阿里云网络拨测工具，发现存在前端 Bug（自动拼错前缀 `undefined.`）。
- **最终解决**：放弃在卡死的旧订单上死磕，直接在控制台取消旧申请。**重新发起一次证书申请，生成了一条全新的 TXT 记录值**。替换解析后，等待 10 分钟，CMD 查到了记录，回控制台点击"验证"，瞬间通过并签发。

> **[插入图片 3：证书列表页截图，展示证书状态变为绿色的"已签发"]**

### 3. 配置 Nginx 开启 HTTPS

- **操作**：下载 Nginx 格式的证书，上传至 `/etc/nginx/ssl/` 目录。
- **配置**：编辑 `/etc/nginx/nginx.conf`（或 `/etc/nginx/conf.d/default.conf`），配置 80 端口重定向至 443 端口，并引入 `.pem` 和 `.key` 文件。

```nginx
server {
    listen 80;
    server_name renzhengdejuju.online www.renzhengdejuju.online;
    return 301 https://$host$request_uri;
}
server {
    listen 443 ssl;
    server_name renzhengdejuju.online www.renzhengdejuju.online;
    ssl_certificate /etc/nginx/ssl/你的证书名.pem;
    ssl_certificate_key /etc/nginx/ssl/你的证书名.key;
    # ... SSL 优化配置省略 ...
    location / {
        root /usr/share/nginx/html;
        index index.html;
    }
}
```

- **验证**：执行 `nginx -t` 测试语法无误，执行 `systemctl restart nginx` 重启。

## ⚠️ 后续维护与避坑指南（重要！）

### 1. 免费 SSL 证书过期问题

- **问题**：个人测试证书有效期为 **90天**。
- **解决**：牢记证书到期时间（可以在手机日历定个提前 10 天的闹钟）。到期前，重新去阿里云申请一张新证书，下载后替换服务器上 `/etc/nginx/ssl/` 目录里的旧文件，再次重启 Nginx 即可。

### 2. 域名续费与实名认证

- **问题**：域名是**按年租赁**的，一旦到期未续费，会被注册局收回。
- **解决**：关注阿里云续费通知，及时续费。如果修改了域名的持有者信息，必须重新进行域名实名认证，否则会被暂停解析（Serverhold）。

### 3. 防火墙的"双保险"

有时候服务器内部的防火墙（如 Firewalld 或 iptables）会拦截请求。如果安全组放行了 80/443，但网站依然打不开，记得检查服务器内部防火墙：

```bash
# 查看防火墙状态
systemctl status firewalld
# 临时关闭防火墙（用于测试）
systemctl stop firewalld
```

### 4. 网页文件权限问题

- 如果在浏览器里访问页面遇到 `403 Forbidden` 报错，说明 Nginx 没有权限读取你上传的 HTML 文件。
- **解决**：在终端执行 `chmod -R 755 /usr/share/nginx/html/` 赋予读权限。
