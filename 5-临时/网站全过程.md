### 🔒 第三步：安全模块（配置 HTTPS 小锁）

既然要完善安全模块，我们就顺手把 HTTPS 证书配了。虽然备案没下前，域名访问可能被拦截，但**不影响你用 IP 配置和验证**。

1. **申请免费证书**：
   * 去阿里云控制台，搜索“数字证书管理服务”（SSL证书）。
   * 点击“免费证书” -> “创建证书”。（阿里云每年提供 20 张免费的单域名证书，有效期 3 个月）。
   * 创建后，点击“下载”，选择 **Nginx** 格式，你会得到一个 `.pem` 文件和一个 `.key` 文件。

2. **上传证书到服务器**：
   * 用 WinSCP 把这两个文件上传到服务器的这个目录下：`/etc/nginx/`（建议在里面新建个文件夹，比如 `/etc/nginx/ssl/`，把证书放进这个文件夹）。

3. **修改 Nginx 配置**：
   * 在 WinSCP 里进入 `/etc/nginx/` 目录，找到 `nginx.conf` 文件。
   * 右键点击它，选择“用编辑器编辑”（或者下载到本地修改后再传上去）。
   * 找到里面 `server { listen 80; ... }` 这段代码，把它替换成下面这样（**注意把证书文件名替换成你刚才下载的文件名**）：

```nginx
# 把 HTTP 请求强制跳转到 HTTPS
server {
    listen 80;
    server_name 8.159.145.12; # 备案下来后，把这里改成你的域名
    return 301 https://$host$request_uri;
}

# 配置 HTTPS
server {
    listen 443 ssl;
    server_name 8.159.145.12; # 备案下来后，把这里改成你的域名

    # 你的证书路径
    ssl_certificate /etc/nginx/ssl/你的证书文件名.pem;
    ssl_certificate_key /etc/nginx/ssl/你的证书文件名.key;

    # 其他 SSL 安全配置
    ssl_session_timeout 5m;
    ssl_protocols TLSv1 TLSv1.1 TLSv1.2;
    ssl_ciphers ECDHE-RSA-AES128-GCM-SHA256:HIGH:!aNULL:!MD5:!RC4:!DHE;
    ssl_prefer_server_ciphers on;

    # 你的网页文件目录
    location / {
        root /usr/share/nginx/html;
        index index.html index.htm;
    }
}
```

4. **重启 Nginx 生效**：
   * 回到阿里云 Workbench 黑窗口，输入以下命令检查配置是否正确：
     ```bash
     nginx -t
     ```
     *(如果显示 `syntax is ok` 和 `test is successful` 就说明写对了)*。
   * 然后重启 Nginx：
     ```bash
     systemctl restart nginx
     ```

5. **验证小锁**：在浏览器输入 `https://8.159.145.12`。虽然因为是用 IP 访问，浏览器可能会提示“证书不匹配”（这是因为证书是绑定域名的，而你用的是 IP），但你会发现地址栏出现了 `https://`，且可以强制继续访问。**等你的备案下来，域名解析生效后，用域名访问就会显示出完美的绿色小锁了！**

在 Nginx 的 `nginx.conf` 配置文件里，它的结构是层层嵌套的。为了让你彻底明白，我给你画个结构图：

```text

events {
    ...
}

# 核心区域
http {
    # 这里通常会有一大堆配置，比如 include mime.types 等
    
    # 🌟 注意：咱们的 server 块，必须放在 http 的【大括号里面】！
    server {
        listen 80;
        server_name ...
        # ... 里面的内容 ...
    }
    
    # 如果有多个 server，也是并列放在 http 里面的
    server {
        listen 443 ssl;
        server_name ...
        # ... 里面的内容 ...
    }
}
```

1. 你用 WinSCP 打开 `nginx.conf`。
2. 往下拉，找到 `http {` 这个词。
3. 把咱们上一步写的那 **两个 `server { ... }` 块**，**整个复制粘贴到 `http { }` 的大括号里面**。
4. **如何处置原来的 `server`？**
   如果你打开文件，发现 `http { }` 里面本来就有一个默认的 `server { listen 80; ... }`（通常写着 `server_name _;`），**请把它删掉，或者用 `#` 号注释掉**。用咱们新写的这两个 `server` 块替代它。如果不删掉，Nginx 会报端口冲突的错误。

## 第三阶段：HTTPS 安全加固（最曲折的部分）

### 1. 申请免费 SSL 证书
*   **操作**：在阿里云“数字证书管理服务”中，领取“个人测试证书（免费版）”。
*   **踩坑记录 1：找不到免费入口**。
    *   **问题**：直接在首页点购买，发现都要钱。
    *   **解决**：必须进入“证书管理” -> “SSL证书管理” -> 点击“个人测试证书（原免费证书）”页签才能领取。

### 2. DNS 验证卡死（ERR_EMPTY_RESPONSE / 验证失败）
*   **问题现象**：在证书申请页面添加了 `TXT` 记录后，点击“验证”一直提示“未检测到DNS记录值”。
*   **排查过程**：
    *   本地 CMD 执行 `ipconfig /flushdns` 刷新缓存（需要管理员权限）。
    *   使用 `nslookup -type=TXT _dnsauth.renzhengdeju.online 223.5.5.5` 指定阿里云公共 DNS 查询，一直报 `Non-existent domain`。
    *   使用阿里云网络拨测工具，发现存在前端 Bug（自动拼错前缀 `undefined.`）。
*   **最终解决**：放弃在卡死的旧订单上死磕，直接在控制台取消旧申请。**重新发起一次证书申请，生成了一条全新的 TXT 记录值**。替换解析后，等待 10 分钟，CMD 查到了记录，回控制台点击“验证”，瞬间通过并签发。
*   > **[插入图片 3：证书列表页截图，展示证书状态变为绿色的“已签发”]**

### 3. 配置 Nginx 开启 HTTPS
*   **操作**：下载 Nginx 格式的证书，上传至 `/etc/nginx/ssl/` 目录。
*   **配置**：编辑 `/etc/nginx/nginx.conf` （或 `/etc/nginx/conf.d/default.conf`），配置 80 端口重定向至 443 端口，并引入 `.pem` 和 `.key` 文件。
    ```nginx
    server {
        listen 80;
        server_name renzhengdeju.online www.renzhengdeju.online;
        return 301 https://$host$request_uri;
    }
    server {
        listen 443 ssl;
        server_name renzhengdeju.online www.renzhengdeju.online;
        ssl_certificate /etc/nginx/ssl/你的证书名.pem;
        ssl_certificate_key /etc/nginx/ssl/你的证书名.key;
        # ... SSL 优化配置省略 ...
        location / {
            root /usr/share/nginx/html;
            index index.html;
        }
    }
    ```
*   **验证**：执行 `nginx -t` 测试语法无误，执行 `systemctl restart nginx` 重启。

## ⚠️ 后续维护与避坑指南（重要！）

### 1. 免费 SSL 证书过期问题
*   **问题**：个人测试证书有效期为 **90天**。
*   **解决**：牢记证书到期时间（可以在手机日历定个提前 10 天的闹钟）。到期前，重新去阿里云申请一张新证书，下载后替换服务器上 `/etc/nginx/ssl/` 目录里的旧文件，再次重启 Nginx 即可。

### 2. 域名续费与实名认证
*   **问题**：域名是**按年租赁**的，一旦到期未续费，会被注册局收回。
*   **解决**：关注阿里云续费通知，及时续费。如果修改了域名的持有者信息，必须重新进行域名实名认证，否则会被暂停解析（Serverhold）。

### 3. 防火墙的“双保险”
*   有时候服务器内部的防火墙（如 Firewalld 或 iptables）会拦截请求。如果安全组放行了 80/443，但网站依然打不开，记得检查服务器内部防火墙：
    ```bash
    # 查看防火墙状态
    systemctl status firewalld
    # 临时关闭防火墙（用于测试）
    systemctl stop firewalld
    ```

### 4. 网页文件权限问题
*   如果在浏览器里访问页面遇到 `403 Forbidden` 报错，说明 Nginx 没有权限读取你上传的 HTML 文件。
*   **解决**：在终端执行 `chmod -R 755 /usr/share/nginx/html/` 赋予读权限。

    systemctl stop firewalld
    ```

### 4. 网页文件权限问题
*   如果在浏览器里访问页面遇到 `403 Forbidden` 报错，说明 Nginx 没有权限读取你上传的 HTML 文件。
*   **解决**：在终端执行 `chmod -R 755 /usr/share/nginx/html/` 赋予读权限。
