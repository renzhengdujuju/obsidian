# 公司导航网站使用说明

## 网站简介

公司导航网站是公司统一的内部办公入口，里面集中整理了公司内部系统、常用办公工具、部门专属系统及其他常用网站。

日常工作中，可以先进入公司导航网站，再通过对应入口访问相关系统，不需要单独记住每个系统的网址。

## 默认页面

登录成功后，首先进入默认导航页面。

页面中按照不同用途展示了常用的网站入口。找到需要使用的系统后，点击对应入口即可访问。

![](https://static.lingman.tech:9005/cai/zt/training/20261026/36e0e68dc7a64fc0af6fc859543f8023/image.png)

如果暂时找不到需要使用的系统，可以通过页面中的分类或搜索功能进行查找。

## PWA 是什么

PWA 的英文全称是 Progressive Web App，中文一般称为“渐进式 Web 应用”。

简单来说，PWA 就是把网页安装成一个可以直接打开的应用。安装完成后，电脑桌面或开始菜单中会出现对应的应用图标，以后直接点击图标就可以打开，不需要每次重新输入网址。

PWA 本质上仍然是网页，安装后一般会在独立窗口中打开，使用起来和普通软件比较接近，但不等同于单独下载安装的客户端软件。

需要注意以下几点：

1. PWA 通常需要网络连接才能正常使用。
2. 网站更新后，重新打开应用即可使用最新内容。
3. 不是所有系统都支持安装为 PWA，是否可以安装以页面实际显示为准。
4. PWA 和客户端软件的安装方式不同，具体要根据页面显示的按钮进行操作。

### “Web 安装”和“下载”的区别

在页面中看到以下按钮时，可以按照对应方式操作：

- **“Web 安装”或“安装应用”**：表示可以直接把网页安装成应用。一般不需要下载单独的安装文件，点击后按照浏览器提示完成安装即可。
- **“下载”**：表示需要先下载客户端安装文件，再打开安装文件，按照安装提示完成安装。这种方式安装的是客户端软件，不是 PWA。

简单来说：

> “Web 安装”是把网页安装成应用；“下载”是下载安装客户端软件。

## 安装方法

下面以“部署中心”为例，说明如何从导航网站进入并安装系统。

### 1. 进入部署中心

在默认导航页面中找到“部署中心”，点击进入。

![](https://static.lingman.tech:9005/cai/zt/training/20261027/748fad652bfa4321b884c7fed6658774/image.png)

### 2. 选择安装方式

进入部署中心后，找到需要使用的系统，并查看页面显示的安装方式。
这里出现的是“下载”，点击“下载”。
![[Pasted image 20261027140813.png]]

下载安装客户端软件，根据页面提示完成安装。

![](https://static.lingman.tech:9005/cai/zt/training/20261027/408905fbdb3b4bee8054497cc18a9a8a/image.png)

安装完成后，可以从桌面、开始菜单或浏览器的应用列表中打开已安装的应用。

## 使用注意事项

1. 请通过公司导航网站进入工作系统，不要随意使用来源不明的链接。
2. 建议使用 Chrome 或 Edge 浏览器访问和安装。
3. 如果页面没有显示安装选项，请以页面提供的其他使用方式为准。
4. 如果安装后没有在桌面看到应用图标，可以在 Windows 开始菜单中搜索系统名称。
5. 不同系统的安装入口和提示内容可能略有不同，请以实际页面显示为准。
