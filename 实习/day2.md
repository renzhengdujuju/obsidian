# 公司导航网站使用说明## 
## 网站简介

公司导航网站是统一的内部办公入口，用于集中访问公司内部系统、常用办公工具、部门专属系统及其他常用网站。

通过导航网站可以减少查找网址的时间，方便员工快速进入日常使用的办公系统。

## 如何进入网站

打开浏览器，在地址栏输入以下网址：

https://daohang.81code.cn/#/home

![](https://static.lingman.tech:9005/cai/zt/training/20261026/2c888eee6518463f901ab6510d88e889/image.png)

打开后会进入登录页面。系统会优先识别当前已登录的企业微信账号，识别成功后即可直接登录。

如果系统未能自动识别账号，可以使用登录页面右上角的二维码扫码登录。

> 注意：目前在企业微信桌面端内打开网站可能会出现登录异常。遇到这种情况，请选择“继续在浏览器中登录访问”，不要直接在企业微信内打开。

![](https://static.lingman.tech:9005/cai/zt/training/20261027/e7d8abf3d2e24aea8e13c994fcb87a1b/image.png)

完成登录认证后，即可进入

登录成功后，首先进入默认导航页面。

页面中按照不同用途展示了常用的网站入口。找到需要使用的系统后，点击对应的入口即可访问。

![](https://static.lingman.tech:9005/cai/zt/training/20261026/36e0e68dc7a64fc0af6fc859543f8023/image.png)

如果暂时找不到需要访问的系统，可以使用页面中的分类或搜索功能进行查找。

## 将网站安装为应用

公司导航网站支持安装为 Web 应用。安装后，可以像打开普通软件一样，从桌面或开始菜单直接打开，不需要每次重新输入网址。
安装后的应用仍然通过浏览器运行，网站内容和网页版保持一致。网站更新后，重新打开应用即可使用最新内容。

### 使用注意事项

- 请通过公司导航网站进入工作系统，不要随意使用来源不明的链接。
- 建议使用 Chrome 或 Edge 浏览器进行安装。
- 如果页面中没有显示安装选项，请确认已完成登录，并检查浏览器是否为最新版本。
- 安装应用后，首次打开时仍需要按照系统要求完成登录认证。
- 如果无法打开应用，可以先打开公司导航网站，完成登录后再重新进入对应系统。
- 不同系统的安装入口和提示内容可能略有不同，请以实际页面显示为准。
