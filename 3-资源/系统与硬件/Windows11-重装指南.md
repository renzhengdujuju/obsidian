💻 Windows 11 系统重装项目总结与后续配置指南  
  
📌 一、 项目背景与准备工作  
  
· 初始状态：电脑原系统为银河麒麟（Kylin）桌面操作系统，需全盘重装为 Windows 11。  
· 所需工具：  
  · 8GB 以上容量的 U 盘一个。  
  · Ventoy 或 Rufus 启动盘制作工具。  
  · Windows 11 系统 ISO 镜像文件。  
  
---  
  
🛠 二、 完整安装流程回顾（从按 F7 开始）  
  
1. U盘引导启动：插入制作好的 Ventoy U盘，开机后立刻反复敲击 F7 键（部分主板可能是 F12/F8/F11）进入启动菜单。选择带有 “UEFI” 前缀的 U盘启动项。  
2. 选择镜像：在 Ventoy 菜单中，方向键选中 Windows 11 的 ISO 镜像，按回车，选择正常模式启动。  
3. 进入安装界面：点击“下一页” -> “现在安装” -> 选择“我没有产品密钥”（如有可输入）。  
4. 磁盘分区处理（核心）：选择“自定义：仅安装 Windows (高级)”。此时会看到硬盘列表（如之前的“磁盘0”和“磁盘1”）。  
5. 自动部署：选中目标磁盘的“未分配空间”，点击“下一步”，系统自动复制文件。  
6. 重启拔U盘：进度条走完后电脑会自动重启，在屏幕变黑重启的瞬间，立刻拔掉 U 盘，防止再次循环进入安装界面。

🚨 三、 安装过程中遇到的问题与解决方法  
  
1. 磁盘显示“未知”或无法点击“下一步”  
  
· 原因：原麒麟系统使用的分区格式（如 EXT4）或引导模式（GPT/MBR）Windows 无法直接识别。  
· 解决方法：  
  · 在安装界面选中报错的磁盘分区，点击下方的 “删除(D)”，使其变成“未分配空间”，然后选中它直接点“下一步”。  
  · 终极大法：在安装界面按 Shift + F10 调出命令行，输入以下命令清空并转换磁盘格式：  
    ```cmd  
    diskpart  
    list disk  
    select disk X  (X代表你要清理的硬盘编号，千万别选错U盘)  
    clean  
    convert gpt  
    exit  
    ```  
  
2. 要求强制联网并登录微软账户  
  
· 解决方法：在“让我们连接您到网络”的界面，按下 Shift + F10 调出命令行，输入以下命令并按回车：  
  ```cmd  
  start ms-cxh:localonly  
  ```  
  系统会直接跳转到创建本地账户的界面。此外，也可以尝试输入 oobe\bypassnro（系统会重启，之后会出现“我没有 Internet 连接”的选项）。  
  
3. 插了网线却没有网络（有线网卡不工作）  
  
· 排查步骤：  
  1. 物理检查：查看网口指示灯是否亮起，重新插拔网线，确保路由器端插在 LAN 口。  
  2. 设备管理器：右键开始菜单 -> 设备管理器 -> 网络适配器。查看是否有带黄色感叹号的“以太网控制器”（说明缺驱动）。  
  3. 网络重置：设置 -> 网络和 Internet -> 高级网络设置 -> 网络重置。  
  4. 命令重置：管理员终端输入 netsh winsock reset 和 ipconfig /flushdns 后重启。  
· 💡 最终发现：使用第三方软件（驱动总裁）检测时发现，系统打上了 Wi-Fi 6 无线网卡驱动，但缺少有线网卡（LAN/Ethernet）驱动。  
· 终极解决：连接 Wi-Fi 或通过手机 USB 共享网络给电脑，前往主板/整机（AZW）官网下载对应型号的有线网卡驱动，或让 Windows 更新自动抓取。

⚙ 四、 系统安装好后的常见操作清单（新机优化）  
  
系统初次进入桌面后，建议按以下顺序进行配置：  
  
1. 系统激活与更新  
  
· 检查激活：进入“设置” -> “系统” -> “激活”，确认系统已激活（品牌机联网通常会自动激活）。  
· Windows 更新：进入“设置” -> “Windows 更新”，点击“检查更新”。这能修补漏洞并自动补充缺失的基础硬件驱动。  
  
2. 基础软件安装（按需）  
  
· 解压缩：7-Zip（免费开源无广告）或 WinRAR。  
· 浏览器：Edge（自带）、Chrome。  
· 办公通讯：Office/WPS、微信、QQ。  
· 输入法：搜狗、微信输入法。  
  
3. 系统习惯优化与“去广告”  
  
· 找回常用图标：右键桌面 -> 个性化 -> 主题 -> 桌面图标设置，勾选“此电脑”、“控制面板”、“回收站”。  
· 关闭系统广告：设置 -> 隐私和安全性 -> 常规，关闭所有个性化广告选项。  
· 关闭通知干扰：设置 -> 系统 -> 通知，取消勾选“获取来自应用和其他发送者的通知”。  
· 开启存储感知：设置 -> 系统 -> 存储，打开“存储感知”自动清理垃圾。  
  
4. 安全防护与避坑指南  
  
· ⚠ 警惕流氓软件：使用第三方驱动软件（如驱动总裁、360驱动大师）时，务必看清按钮，拒绝捆绑安装的“清理大师”、“安全卫士”等无关软件。  
· 杀毒软件：Windows 11 自带的 Windows 安全中心（Defender） 极其强大，完全够用，强烈建议不要安装 360、电脑管家、鲁大师等第三方全家桶。  
  
5. 系统备份（高阶操作）  
  
· 当所有驱动和常用软件都安装完毕，且电脑运行流畅时，建议在“控制面板”中开启“系统保护”（创建还原点），或者使用 PE 系统（如微PE）备份一次 C 盘镜像。以后系统出问题可直接还原，免去重装麻烦。
