# RaiDrive 云端文件管理实验记录

## 什么是 RaiDrive

RaiDrive 是一款把网盘、云存储和远程服务器上的文件，映射成电脑本地磁盘的软件。

安装 RaiDrive，并创建 New Drive 映射到本地盘符 Z 进行连通性测试，最终通过 Google Drive 测试成功。

## 任务一：搭建云端文件工作区

1. 创建 04-Project-Alpha、05-Backup-Lab、06-Automation 三个目录模拟项目的工作目录。
2. 已在 RaiDrive 映射盘中找到该文件，并且在 Google Drive 网页端确认该文件存在。

## 任务二：云端文件的备份与恢复

1. 原始文件 V1 已创建，并且能在网页端访问。
2. Alpha-Backup-V1 中存在独立的 V1 备份副本。
3. 原文件已成功修改为 V2-ERROR，模拟了误操作。
4. 恢复后的 business-data.txt 包含客户数量 120、订单数量 350。
5. 错误版本已单独保留，备份副本仍然完整。

## 任务三：用 PowerShell 自动整理文件

1. 编写自动化脚本在 PowerShell 中测试运行，并生成实验报告。
2. 对本地 Input 文件夹里的数据进行整理，并备份一份原数据到 Output 文件夹。
3. 增加 SHA-256 用于验证文件内容一致性的校验。
4. 将创建并测试的 Output 文件夹放入 RaiDrive 中，实现与云端的互联。
5. 最终实现本地文件通过 PowerShell 分类、复制、生成报告，再通过 RaiDrive 上传到云端。

## 任务四：测试 RaiDrive 的云端文件系统特征

1. 计算原始文件和分类后文件的 SHA-256，并比较两者是否一致。
2. 检查副本是否存在，不存在则显示缺失。
3. 检查 CSV 报告。

## 任务五：对整个流程进行升级

1. 引入时间戳，按时间戳创建备份目录。
2. 引入日志，可快速定位问题。
3. 允许单文件出错，避免出现一个文件出错就立即停止的情况。

## 任务六：定时备份

1. 优化检测逻辑。
2. 设置每天晚上八点自动备份。
