# 公司导航网站使用说明（新人版）

> **网址**：https://daohang.81code.cn/#/home
> **这是干什么**：公司所有内部系统的统一入口。找系统、进系统，都从这里走。
> **你需要准备**：一台电脑（推荐 Chrome 或 Edge 浏览器）+ 你的企业微信账号

---

## ⚡ 30 秒上手

| 步骤 | 做什么 |
|---|---|
| 1 | 浏览器打开上面的网址 |
| 2 | 用**企业微信 App** 扫码登录 |
| 3 | 在主页点你要的系统图标，直接进入 |

就这三步。卡在哪一步，往下看对应章节。

---

## 一、首次登录

### 1. 打开网站

浏览器地址栏输入 `daohang.81code.cn`，回车。

![[导航站-01-浏览器输入网址.png]]
> 图：地址栏输入后，点下拉提示里的"导航管理"即可进入

### 2. 扫码登录

打开后会弹出登录窗口：

- 电脑上**已登录企业微信** → 页面自动识别你的账号，按提示确认即可
- **没自动识别** → 点"授权登录"，用企业微信 App 扫二维码
- 想用**微信**扫 → 点弹窗下方的"切换成微信扫码登录"

![[导航站-02-企业微信扫码登录.png]]
> 图：扫码登录窗口；底部可切换成微信扫码

### 3. 在企业微信里打开、登录不上？

在企业微信里直接打开容易登录异常。看到下面这个界面时，点"**继续在浏览器中登录访问**"，不要点"在企业微信桌面端打开"。

![[导航站-03-企业微信内打开的提示.png]]
> 图：企业微信内打开时的界面——点红线的"继续在浏览器中登录访问"

## 二、找到你要的系统

登录后进入主页，系统按分类排好，点图标直接进入。

![[导航站-04-主页.png]]
> 图：导航站主页，系统按分类排列

新人常用的系统速查：

| 分类 | 系统 | 干什么用 |
|---|---|---|
| 行政管理 | **日报** | 每天写工作日报 |
| 行政管理 | **工作台** | 日常工作的统一入口 |
| 行政管理 | **新人报到** | 入职相关手续和材料 |
| 行政管理 | **公司IT** | 电脑、网络、账号出问题，从这里找 IT |
| 行政管理 | 人事系统 | 考勤、假期、人事信息 |
| 实用工具 | 文件中转站 | 给同事传大文件 |
| 实用工具 | 粘贴系统 | 文字、内容快速粘贴分享 |
| 开发相关 | Gitlab | 代码仓库 |
| 开发相关 | 部署中心 | 下载公司内部软件 |
| 文档相关 | 公共文档中心 | 查公司公共文档、制度 |

> 以上是常见用法，具体以系统实际内容为准。
>
> 表里没有的 → 用主页的**分类**或**搜索**功能找。

## 三、把系统装成桌面应用（可选）

装好后的效果：**桌面和开始菜单出现图标，以后双击图标直接打开，不用再输网址。**

安装时看页面给的按钮，见到什么点什么：

| 页面显示 | 怎么做 |
|---|---|
| **Web 安装 / 安装应用** | 点它 → 按浏览器提示完成 → 网页直接变成应用 |
| **下载** | 点下载 → 打开下载的安装包 → 像装普通软件一样点下一步 |

装好后，从桌面或开始菜单双击图标就能打开。

---

## 四、遇到问题

| 问题 | 解决 |
|---|---|
| 企业微信里打开，登录异常 | 点"继续在浏览器中登录访问"，用浏览器打开 |
| 装完桌面没图标 | 开始菜单里搜系统名 |
| "Web 安装"和"下载"分不清 | 两个都是装成桌面应用：Web 安装是网页直接变应用；下载是先装客户端。看到哪个点哪个 |
| 找不到某个系统 | 主页用搜索；还没有就是没接入导航站，问导师或同事 |
| 其他电脑 / 网络 / 账号问题 | 主页 → 行政管理 → **公司IT**，提交问题给 IT |

> 最后提醒：只从导航站进系统，不要点来源不明的链接。
